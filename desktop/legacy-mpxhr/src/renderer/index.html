Cloud Sync

Linking to Google Drive ensures your data is secured off-site automatically.

Setup Google Drive Backup:

  1. Install Google Drive for Desktop.
  2. Locate your HRMS_OFFSITE_BACKUPS folder in Explorer.
  3. In Settings > Database Maintenance, click Change Folder.
  4. Select the Google Drive folder and Enable "Auto-Backup on Exit".
System Corruption Alert: If Windows fails, a local backup will be lost. Always maintain an off-site copy in the cloud!
